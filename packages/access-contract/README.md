# 授权公共契约

包名：`@platform/access-contract`。这是可同时被前后端消费的小型无框架依赖包。

| 目录 | 内容 |
| --- | --- |
| `src/permissions/` | `模块:功能:操作` 权限名称及类型 |
| `src/resources/` | M/C/F 资源类型与清单所需的公共约定 |
| `src/data-scope/` | 六种数据范围的名称、值和类型 |

仅共享词汇与契约，不实现认证、不判断当前用户权限、不构造 SQL，也不导出数据库表。具体接口 DTO 由 Elysia schema 和 Eden 推导，避免重复维护。

当前入口导出 `ALL_PERMISSION = '*:*:*'`，表示后端确认的超级管理员全权限；普通资源不能配置该标识。具体业务权限清单与枚举在对应模块落实时添加。
