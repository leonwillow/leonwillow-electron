# 资金调查工作台

范围：/funds（资金分析）与 /funds/cases（案件管理）。模式：Operate。用户为经侦、职务犯罪办案人员，用整案资料导入、核对后，按自主选择的账户、交易或双方往来继续追踪。首版不推定犯罪或原款归属。

## Direction contract

THESIS：以案件资料与可核对交易作为工作入口，保留整案基础，允许任意选择分析起点；不预设四筆付款等演示路线。

OWN-WORLD：扩展现有 AIDesk 工作区，沿用 Base UI / base-mira、语义色、共享字体与 rem 缩放；现有紫色主题由用户设置决定。办公桌面为主，同时支持窄窗口。

STORY：先按案件上传原始流水，AI 统一模板，后台显示标准化、去重和图入库结果；再选择账户与日期查看图、交易及原始行。跨案只提示线索，明确确认后纳入，允许排除。

FIRST VIEWPORT：侧导航只提供一个资金分析入口。其右侧是参考用户提供 Codex 菜单结构的案件列表，可搜索并选择案件；未固定时悬停展开，固定后在宽窗口常驻一列，窄窗口使用可关闭浮层，避免挤压正文。二级菜单没有 X 按钮，浮层可通过移出、点击外部或 Escape 关闭；拖动时保持展开。右上角固定按钮保存当前用户的偏好，列表是案件选择的唯一常规入口，移除原下拉框。顶部提供新增和归档入口；搜索通过尾部按钮或回车提交。普通视图将置顶与普通案件分区，原生拖放或 Alt+上下方向键保存分组内顺序。行内操作在鼠标悬停时显示，点击焦点不常显；键盘 focus-visible 和触屏保留入口。菜单顶部、搜索及行内操作图标均提供 Tooltip，置顶和恢复用共享 success、归档用 warning、删除用 destructive。顶部归档按钮切换整个菜单为已归档列表并提供返回；归档可恢复，仅归档案件可经确认删除。首次进入不默认打开案件，选择之后才显示“分析 / 案件管理”内部导航。二级栏底部不再保留管理入口。分析正文直接进入账户目录、筛选、资金图和交易明细，不挂载选案、导入、任务或清洗管理面板。内部案件管理集中模板下载、文件与导入、清洗核对和跨案线索。

FORM：沿用用户指定的已有后台工作区结构，属于既有系统扩展；无随机 seed，无新视觉世界或 image comp。主图标栏、案件菜单和资金页头共用 workspace-header 高度与分隔线；菜单及资金模块标题同级居中，案件名以箭头分层、长名省略。窄窗口标题分两行且顶栏高度不变，内部导航保持单行。标志性交互是图、交易行和来源核对相互连接；资料准备与分析分开，保留现有完整处理记录与跨案明确纳入、可撤销排除。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

约束：案件基于用户授权的 16 个测试文件，原始文件按案件保存至 RustFS，提供原件下载与哈希核验；分析仅采用已导入资料。归档案件的删除只标记删除并取消未完成任务，PostgreSQL、Neo4j 与 RustFS 资料保留；确认弹窗明确此边界，当前没有恢复已删除案件的界面。上限、待核、仅见对手的资料缺口明确显示。保留既有设计规则，操作颜色归共享语义令牌和 Button 变体，不为此扩展重写全局 DESIGN.md。
