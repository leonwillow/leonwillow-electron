# 资金调查界面与验证记录

创建及维护日期：2026-10-06。版本：v8。范围：`/funds`（分析）、`/funds/cases`（案件管理）、`apps/web/src/views/funds` 与工作区二级案件菜单。两页均属于资金分析模块。记录当前界面、共享规范依据及分版本验证边界；导入规则、数据模型和未实现能力分别见[导入规范](./funds-import.md)与[案件处理与分析](./funds-investigation-design.md)。

## 现有界面体系

资金调查扩展现有 AIDesk 工作区，保留侧导航、主题设置和 Base UI / base-mira 组件体系。原模板 `src/views/inbox` 与 `src/components/ui` 已查阅；原组件负责工作区与控件的视觉来源，资金调查的业务布局和图查询由当前功能实现，不引入原模板的 Next.js 运行时。

二级案件菜单的交互结构依据用户提供的截图，栏宽、页头、边框和案件行沿用原模板 `src/components/layout/KnowledgeBaseSidebar.tsx`：侧栏语义背景、固定宽度与共享按钮导航。当前案件行使用 `ghost` 链接，选中、悬停和键盘 `focus-visible` 由行容器的 `sidebar-accent` 表达，给同行操作留出位置。搜索复用共享 `InputGroup` 的尾部图标按钮，新增和删除确认复用 `Dialog`，字段复用 `Field` 和 `Input`，字体和控件尺寸继续来自共享组件。置顶、取消置顶及恢复使用共享 `success` 按钮，归档使用 `warning`，删除使用 `destructive`；颜色由 `globals.css` 中对应语义令牌统一维护明暗状态，配合图标名称和 Tooltip 表达用途。当前视觉权威为用户截图、该模板组件、[UI 规范](./ui-conventions.md)及共享令牌；本轮没有独立 image comp、QUALITY BAR 卡片或新的 DESIGN 文件。

## 页面与交互

侧栏与命令搜索只提供一个“资金分析”入口，两页共用 `funds` 权限；进入内部案件管理页时，侧栏仍选中资金分析。共享 `FundsHeader` 统一显示“资金分析”标题；选择案件后才显示“分析 / 案件管理”内部链接，切换时携带当前 `caseId` 并精确标记当前页面。原模板 `SettingsNav` 的按钮导航方式适配为共享 `buttonVariants` 的选中 `secondary`、未选中 `ghost` 样式，不增加视觉体系。原“案件资料”和“进入分析”独立按钮已移除，常规跨页操作统一使用内部导航。刷新可恢复 URL 指定的案件；没有指定 `caseId` 时保持未选案，不自动打开列表首案。账户、日期、追踪、分页和管理页签仍是各自页面的局部状态，跨页或刷新不保证恢复。

主图标栏顶部、案件菜单顶部与资金页头共用 `workspace-header` 高度令牌（3.5rem）并禁止压缩，三处底部分隔线保持一致。菜单标题与“资金分析”均使用 `text-base` 并垂直居中，菜单顶部图标采用共享 `size="icon"`。资金页头用箭头分隔模块名与案件名，长案件名省略显示并保留完整名称提示；窄窗口隐藏箭头，将模块名与案件名排成两行，顶栏仍保持同一固定高度。右侧内部导航始终单行，不因标题长度换行。

主图标栏右侧的二级“案件”菜单是当前常规选案入口，提供案件名称搜索、当前案标记和点击切案；原案件管理下拉框及菜单底部“案件管理与导入”链接均已移除。案件列表在分析页切案后仍留在分析页，在案件管理页切案后仍留在案件管理页，并更新 URL 的 `caseId` 和对应正文。输入搜索文字后，按 Enter 或点击尾部“执行案件搜索”图标才提交名称筛选；清空后也需提交。搜索作用于当前案件列表或已归档列表。读取中、空列表、无匹配结果和读取失败分别显示提示，读取失败可重试。

菜单顶部加号打开“新增案件”对话框。创建成功刷新案件列表并进入该案的案件管理页，默认显示“文件与导入”；创建失败保留名称与错误提示，提交期间阻止重复提交。案件管理页不再保留第二个新建入口。

普通菜单将“置顶”和“案件”分成独立区域，空分组不显示。案件行仅在鼠标悬停时显示操作按钮，鼠标点击留下的普通焦点不会使按钮常驻；键盘 `focus-visible` 和无悬停能力的触屏设备保留入口。菜单操作图标均使用共享 Tooltip，包含顶部、搜索及行内操作，中文名称说明置顶、归档、恢复或删除等用途。案件置顶、归档与顺序由服务端保存，与整个菜单的固定偏好分开。

案件行支持原生拖放，插入位置以共享主色线提示；拖动期间保持浮层展开，避免误导航。排序限于当前分组：置顶组、普通组分别排序，已归档视图整体排序，不通过跨组拖动改变案件状态。键盘聚焦案件链接后可用 Alt+上 / 下方向键移动。服务端按当前完整分组保存顺序，搜索隐藏项不会被客户端的筛选列表覆盖；保存后刷新恢复顺序，失败在菜单内显示错误。

顶部“查看已归档案件”按钮将整个菜单切换为“已归档”视图，显示返回按钮及归档搜索，不混入置顶或普通案件；返回普通菜单时清除前一视图的搜索。归档行提供恢复与删除，普通行提供置顶与归档。归档当前案件同时退出到未选案的资金分析页；归档可恢复，不删除资料。

删除仅在已归档案件中提供，服务端也拒绝删除未归档案件。确认弹窗列出案件名，并明确原始文件、流水和图数据保留、未完成后台任务停止；可取消，提交期间禁用重复操作，失败留在弹窗内重试。确认后 API 只标记案件删除并取消未完成任务，不清除 PostgreSQL、Neo4j 或 RustFS 资料，Worker 不再领取已删除案件。案件从列表和正常业务访问中移除；删除当前案件退出到未选案页。当前界面没有恢复已删除案件的入口。

菜单未固定时，悬停或聚焦资金图标展开，移出图标与菜单后关闭；键盘可见焦点仍在菜单内或正在拖动时保留展开，也可点击外部或按 Escape 关闭。二级菜单不再显示 X 收起按钮。右上角固定按钮按用户将偏好保存在 `localStorage`；宽窗口且处于资金模块时，固定菜单独占一列。离开资金模块后不常驻，返回时恢复固定偏好。低于 `48rem` 时仍记住偏好，但菜单使用可关闭浮层，不挤压正文；存储不可用时本次会话操作仍生效。

资金图标的悬停反馈由固定偏好决定：已固定时显示“资金分析”提示气泡，不触发浮动菜单；未固定时只展开案件菜单，通过 Tooltip 根组件的 `disabled` 关闭提示交互并清除打开状态，不单独隐藏内容，以免固定后恢复旧气泡。点击图标及 ArrowRight 进入案件菜单的操作继续可用。2026-10-06 回归：真实悬停、固定/取消固定、键盘聚焦与移焦、390px 窄窗口切换均符合预期；鼠标未悬停时切换不显示资金气泡，验证后恢复原固定偏好。

菜单右上角固定按钮使用 TooltipTrigger 的 `closeOnClick=false`：点击切换后仍保留清晰气泡并更新为下一步操作名称，避免默认点击关闭产生的淡出；鼠标移开后正常关闭。此选项仅用于菜单固定开关，其他案件操作保持原行为。2026-10-06 验证鼠标连续切换两态时气泡均为打开状态、透明度 1，Enter 可切换，离开按钮后关闭。

两页的空态和图未就绪状态分别处理：

- 未指定 `caseId` 时，分析页显示“选择案件，开始资金分析”，管理页显示“选择案件，管理流水资料”；两页的“选择案件”按钮均打开菜单并聚焦搜索。菜单无案件时引导点击顶部加号，管理页仍可下载模板。
- 已有案件但没有来源文件时，分析页提示“这个案件还没有流水”并链接案件管理；管理页仍展示默认文件导入入口，文件表显示“当前案件还没有导入文件”。
- 资料版本与图版本不一致时，分析页显示“案件资料正在处理”和“查看处理进度”，暂不挂载分析面板；管理页保留导入、清洗及跨案页签，显示后台更新提示与“重试同步”。管理页仍可进入分析，落到同一案件的处理提示。
- 两页读取中均显示状态提示，案件读取失败提供重试。切换案件重建对应工作区，异步请求通过局部请求代次忽略失效响应。

分析页每 5 秒轻量检查案件列表中的资料/图版本，仅变化时重读案件；页面隐藏时跳过检查，离开页面即停止。已有来源文件且图版本追上资料版本后自动显示分析面板。版本刷新可能重建分析局部状态，不代表筛选或追踪持久化。案件管理通过持续挂载的文件面板接收任务更新。版本列表记录导入、人工配对与跨案纳入/排除，当前没有撤销人工配对决定或回退历史版本的操作。

### 图、明细与追踪

账户目录优先列出已有本方流水的账户，完整覆盖案件中的已知账户，不再截取前 200 项。TanStack Virtual 只挂载可见条目、前后缓冲与当前键盘焦点条目；动态测量行高适配缩放和长账号。方向键、Home/End、PageUp/PageDown 可浏览全部结果，搜索或筛选改变后回到首行。整案图通过独立的 `/cases/:caseId/graph` 接口取得本案全部已入图节点和逐笔交易，包括仅在交易对手位置出现、尚未取得其本方流水的节点。已取得流水与否只影响节点资料标记，不作为交易显示条件；取消旧版双方均有流水和前 150 笔的限制。图与明细共用同一完整查询结果，明细每页显示 50 笔，翻页不重新请求或重建图。账户、日期、对方或方向筛选后，仍完整绘制该范围的交易。接口失败明确报错，不静默返回截断图。

账户目录搜索与二级案件搜索使用相同的共享 InputGroup 组合，搜索图标内嵌右侧，统一高度、圆角、文字及焦点样式，保留中文 Tooltip。点击图标或按 Enter 提交，仍只搜索目录。2026-10-06 验证赵佳搜索返回 8 个账户，清空后回车恢复列表；390px 窗口无横向溢出。

2026-10-07：移除目录顶部的“账户 / 整案视图”行，正文顶部使用与案件栏搜索相同的 `pt-3`，两侧搜索框对齐。搜索右侧独立筛选按钮复用 Popover 与原模板 FilterSelect，可组合流水状态、户名冲突、特殊标记、手动隐藏和最低/最高交易笔数；条件草稿经校验后提交，与搜索取交集，只影响目录。按钮显示已应用状态，弹窗支持重置。当前页面内保留条件，切换案件或重新进入后回到默认。

账户/主体目录不再显示搜索下方的说明段落。列表每行仅保留名称、笔数和账号（主体模式为成员账户数）；名称与笔数保持单行，笔数不收缩，长名称省略。取消截断名称 Tooltip 与列表内标签，改用共享 HoverCard：悬停或键盘聚焦 100ms 后显示完整名称、账号、状态、本案交易/对手数量、流入/流出、差额（流入－流出）和交易区间；移入卡片可继续阅读，Escape 关闭，点击收起预览并打开右侧完整详情。单击详情、双击下钻、右键和 Shift + F10 菜单仍由分析页处理。

预览移除“点击账户查看完整详情”提示；差额与完整详情一致，按币种以 BigInt 相减，不把内部划转计入对外收付。金额格式化从网络模块抽出为 `funds-money.ts`，正确显示负数及不足一元的负差额。

预览只接收当前案件的 `full` 图与节点数据，复用详情的 `summarizeNode`，没有 API 调用。Base UI Portal 仅在打开时挂载内容，避免列表全部节点提前计算收付汇总，并保留退出动画期间的内容；内部划转明细、成员账户与标记操作留在完整详情。预览和详情共用 `NodeStatusTags`：绿色已有流水、黄色待补、红色户名冲突、主题色特殊标记、灰色对手/隐藏状态，使用共享语义令牌且保留文字含义。

目录中的所有条目共用一个 Base UI PreviewCard Root 和 Portal，通过 handle / payload 切换当前账户；快速跨行时只更新同一个浮层，关闭动画也不会留下另一张卡。共享 Arrow 自动指向当前触发条目，卡片内容在内部滚动，箭头不受裁剪。点击、右键、键盘菜单或目录滚动会作废当前悬停，拒绝过期条目的延迟打开回调；下一次移入或聚焦后恢复预览。快速点击后等待超过悬停延迟，右侧详情保持打开且预览数为零，避免两层内容同时出现。

2026-10-06 验证：张世雄速览显示 1,638 笔、165 个对手及与详情一致的收付金额；长户名完整显示且列表保留 274 笔。鼠标悬停、键盘聚焦、点击进入详情均可用；390px 卡片自动改到下方，无横向溢出；深色模式待补标签清晰。`lint`、`check-types`、`build`、`test:ui`（39 项）通过，构建保留既存 G6 大块提示。截图：`apps/web/.impeccable/review/funds-account-preview.png` 与 `funds-account-preview-mobile.png`。

选择账户可查看关联交易；点击图边或表格“核对”按钮打开同一来源弹窗。普通关系查询中的账户、对方、日期及收支筛选发生变化时，清除旧追踪和选择，回到第一页。

追踪可从当前账户或最多 10 笔所选交易出发，层数为 1–4。追踪提交日期范围、起点及深度；对方账号和收支方向用于前面的交易筛选，不作为后续路径必须继续满足的条件。追踪结果按交易 ID 去重，画布与“追踪结果明细”使用同一结果集合，明细仍每页 50 笔。每个起点最多返回 200 条路径，路径上限与明细交易数是不同口径；发生截断时提示缩小时间范围。“返回关系图”退出追踪结果并回到普通查询第一页。

当前 Neo4j 图以主体为节点、规范交易为边，账户用于选择起点并保留在交易属性中；不能仅凭同名归并主体。追踪是交易时间不递减、相邻收付款账号连续的关联路径，主体合并不意味着不同账户余额可以直接相互花用。界面保留资金混同说明，闭环、同额或先后往来不能证明同一笔资金归属或回流。

### 来源核对、标准化与后台处理

来源弹窗展示银行原文、文件名、工作表、原始行号和可展开的 SHA-256；合并交易保留多条来源。长编号和原文换行显示，内容区域在窗口内纵向滚动。原始字段核对不改变原件。

案件管理的“文件与导入”默认“原始文件 · AI 标准化”，另有“已有标准 CSV / Excel”入口。文件选择使用浏览器原生多文件输入；入口列出支持格式、每批 32 个文件、单文件 20 MB 和整批 100 MB 的限制，后端另限制单案 100,000 条原始记录。上传请求期间禁用重复提交；上传成功后可离开页面。

原件字节先保存到 RustFS 私有桶并回读核验 SHA-256；PostgreSQL 保存对象引用、任务、标准 CSV、转换报告及规范交易。保存成功后由独立 Worker 完成 AI 映射、程序逐行校验、13 列标准文件生成、案件归并、规范交易写入 PG 和 Neo4j 投影核验。AI 识别表格映射，程序读取原单元格值；不能确定的内容留在报告。任务不依赖页面存活；案件管理中的“文件与导入”页签保持挂载并轮询，切换管理页签仍可更新案件资料及图版本。离开管理页后任务由独立 Worker 继续执行，分析页使用上述轻量版本检查。刷新后从服务端重新读取任务和报告，不表示账户筛选等局部分析条件也会恢复。

后台处理记录按任务折叠，展示当前阶段、最新消息、完成文件数、自动重试错误与失败后的“从未完成处重试”。完成结果分别列出唯一交易、重复观测、双边对应、待核记录、配对候选、暂缓入图数，以及资料/图版本和入图笔数核验。各文件展示原始行、标准行、待核数；展开后可核对原件保存位置、大小、SHA-256、模型、行数守恒、收支合计、查询反馈、开户资料和工作表映射依据，并分别下载原件、标准 CSV 或 JSON 转换报告。原件下载不必等待标准化完成，CSV 与报告在文件就绪后可用；下载失败在面板内显示错误。阶段历史在独立的“查看各阶段记录”中展开。

“已导入的全部文件”也提供逐文件“下载原件”。跨案纳入条目明确使用“下载纳入快照”，下载名以“纳入快照.csv”结尾，仅包含获准纳入范围，不将来源案完整原件当作本案下载。原件下载经过案件权限检查并核验哈希；排除跨案纳入后不再提供该来源下载。存储迁移与原件比对记录见[导入规范](./funds-import.md#rustfs-原件保存2026-10-06)。

标准模板与整案标准流水 CSV 共用用户确认的 13 个字段，来源定位信息由系统单独保留。交易时间合并日期和时分秒，金额约定为人民币元；模板为无装饰样式的普通表。导出保留合格来源观测，含跨文件重叠与双边记录，因此导出行数和归并后的图交易数不同；页面在导出入口说明这一口径。

### 跨案提示与可撤销纳入

“跨案线索”仅提示当前用户有权访问案件中的相同完整账号、户名、来源案件和版本；未确认时不返回外案交易、金额、余额或时间范围，外案资料也不进入本案查询、汇总和资金图。不能仅凭同名认定同一人。

“选择纳入”先打开确认弹窗，列明来源案件、所选账户、来源版本，以及该版本中以此账户为本方或对方的流水范围。确认后将这部分资料快照加入本案，后台重新归并并更新图；来源后续更新不会自动加入。已纳入行显示来源版本和“排除本次纳入”。排除仅撤销本次快照，保留本案独立取得的资料且不改变来源案件；排除记录可展开查看，仍可再次纳入。来源案件不再返回相同账户线索时，已有快照仍保留排除入口。

## 小窗口与键盘路径

资金分析在宽窗口中将账户目录和分析区并列；低于现有 `xl` 断点时上下排列，账户目录限定高度并局部滚动。两页顶栏高度固定，内部导航保持单行；窄窗口的模块名与可选案件名分成两行，长案件名省略，不将导航挤出视口。管理页案件统计仍可换行，分析筛选项逐步从四列变为两列和单列。表格沿用共享组件的局部横向滚动，证据弹窗限制在视口内。画布尺寸随容器变化，提供“适应画布”按钮。

二级案件菜单在宽窗口固定时参与布局；低于 `48rem` 时始终浮动，菜单列表独立纵向滚动。资金图标获得焦点后，可按 ArrowRight 或在菜单已展开时按 Tab 进入“搜索案件”；浮层内按 Escape 关闭并将焦点交回资金图标。搜索按 Enter 或尾部图标提交；案件行是可用键盘激活的链接，键盘 `focus-visible` 时显示操作按钮，Alt+上 / 下方向键可在分组内排序。新增、搜索、置顶、归档、返回、恢复、删除和固定图标均有中文可访问名称；菜单没有 X 按钮，触屏可点外部关闭浮层。

Canvas 本身没有逐节点键盘导航；其可访问名称明确指出下方明细提供键盘操作。以下为代码提供的替代路径，具体实测范围见下一节：

1. 用 Tab 到“搜索账户或户名”，输入后按 Enter 提交；目录每个账户都是带选中状态的原生按钮，可以通过键盘选择。
2. 通过有标签的日期、对方账号、方向和追踪层数控件设置范围；交易选择使用有中文名称的 Checkbox，追踪与分页使用共享 Button。
3. 用 Tab 到交易行的“核对 N 条”按钮，按 Enter 打开来源；追踪展开的新交易也在同一可操作明细中。
4. 来源弹窗可用 Escape 或“关闭”按钮退出；哈希、任务、逐文件报告和阶段记录使用原生 details/summary 展开。菜单中的新增案件采用表单提交。
5. 跨案行的“选择纳入”可用 Enter 打开确认，Escape 可取消未提交的确认；确认与排除均使用共享 Button，异步提交期间禁用重复操作。

图中可点击节点和边的功能有账户目录、交易明细替代入口。搜索、适应画布及对话框关闭等图标操作保留中文可访问名称。本文不把这些代码路径等同于已完成全部屏幕阅读器或浏览器兼容性验证。
