## 包与职责

`packages/lattice-grid` 导出 `@leonwillow-electron/lattice-grid`，Vite 直接消费 TypeScript 源码；纯数据能力可从 `/core` 子出口使用。包没有应用路由、税务字段、认证或数据库依赖。当前 Web 和未来 Electron renderer 复用同一包。

保留原 GridStore 的排序、筛选、选择、编辑、TSV 粘贴、整批校验、异步提交、撤销/重做、列状态和 CSV 安全转义。保留 GridView 的固定行高虚拟化、键盘导航、拖动选择、冻结与列宽控制；React 视图重组为当前共享 Button、Input、Checkbox、Select、Popover、Tooltip 和 ScrollArea，图标用 Lucide，错误通知用 Sonner。原生单元格容器仍保持 ARIA grid 结构，未用静态 Table 冒充编辑网格。

控件颜色、排版和密度由 `packages/ui/src/styles/globals.css` 管理。网格不另设一份主题，长列表和双向表格滚动使用共享 ScrollArea；控制器测量实际 Viewport，避免滚动、冻结与虚拟范围错位。列分组只表示业务表头，未实现数据透视。

2026-11-06：网格 Viewport 单独使用 `overscroll-behavior: none`，到达横向或纵向边界后停止回弹，避免 macOS 触控板把内容拉离滚动口、露出底层焦点框。正常滚动、键盘焦点和边界不向外层传递滚动的行为保留；其他共享 ScrollArea 的策略不变。

2026-11-06：共享 ScrollArea 的 Viewport 隔离内部堆叠层级，滚动条在其上方，避免被冻结列、表头和汇总行遮挡。网格外框 `overflow: clip` 统一裁到主题圆角，不给内部 sheet/body 新增滚动容器。末行按完整筛选结果的索引标记 `data-last-row`，其数据格和行号格去掉底线；各行当前最后可见列去掉右边线，汇总行号格也去掉底线。虚拟窗口的末尾并非数据末尾，仍保留正常行分隔。

2026-11-06：组名在横向滚动时采用 CSS sticky，停靠点为实际冻结列总宽度加行号列。外层分组按原宽度滚动，内层文字受该组边界约束，因此分组快移出时自然带走标题，不覆盖下一组。尺寸来自已有 `GridView.layout()`，同步列宽、隐藏、冻结与窄窗解除冻结；共享 CSS 管理文字留白和溢出。未增加逐帧 React 状态或额外滚动监听。

2026-11-07：`CellIndicator` 通过 React Portal 挂到真实选中格，边框原生跟随单元格滚动、冻结、列宽和虚拟行挂载，不再在正文上测量坐标、更新 clip-path 来追赶滚动。正文建立独立堆叠上下文，表头和汇总始终覆盖正文；普通格的选中框和编辑框均位于冻结列下方。边框包含单元格的分隔线尺寸，末行和末列仍遵守无重复边框的约定。

点击或键盘切换使用 160ms 匀速过渡，避免临近终点时长时间拖尾。临时装饰层的边框与遮挡边界同步移动，目标格部分位于冻结列下方时，动画终帧只呈现它实际可见的部分，接回真实边框时不会突然消失一截。裁剪容器和四条 2px 边都仅动画 transform，全部动画保持终帧后统一接回。连续点击从当前边框及裁剪位置继续；结束、滚轮/滚动、尺寸变化或卸载均立即清理装饰层及监听。静止状态无滚动坐标测量和 React 逐帧更新；减少动态效果时直接切换。可编辑格悬停仍为 I 形光标，不触发边框；只读格保留复制和键盘语义，不添加选中底色或边框。按最新要求移除填充柄、拖拽填充状态、控制器入口和内核填充事务；拖动仍可扩展选区，但不会改写单元格。

## 业务接入

第一处实际接入是增值税月度测算表。月度 ID、原始申报和调整字段、整数分精度校验、计算暂停说明与缺月补录由业务适配层管理。月份和计算结果不可通过粘贴修改；已存在历史月份的五项原始金额及调增销项、调减销项、调增进项和调减进项均可编辑。编辑事务一次合并全部 patch，再进入现有重算与自动保存流程，避免逐格更新覆盖同批数据。归档方案以 readOnly 模式打开。

年度/联动筛选仍由增值税页面管理，筛选控件与导出/清空操作通过 `toolbarContent` 组合进网格工具栏；不再分页，全部结果通过虚拟滚动展示，税务明细导出仍走完整算法，避免把当前网格页的 CSV 当作全期结果。网格只负责展示和通用编辑；其他页面可以提供完全不同的类型、列定义、单元格渲染和保存回调。

原版收到新 rows 数组会清空历史。针对派生数据重算，新增可选 `reconcileRows="editable"`：仅同序行 ID 和全部可编辑值与已确认状态一致时保留历史；真正外部编辑变化仍重置。撤销/重做重放调整 patch，保留宿主最新只读派生数据，再由宿主重算，不直接拿旧快照覆盖新结果。

网格的复制和数字筛选使用元单位的十进制字符串，领域算法继续使用整数分；避免历史金额复制到调整列时放大一百倍。VAT 关闭通用选区求和，页面顶部的全期计算结果是权威合计。外部数据替换、列失效或进入只读/加载/错误状态时取消陈旧编辑；自身提交与只读派生字段回显不会误触发取消。

单元格编辑改为整格焦点边框，共享 Input/SelectTrigger 新增 `cell` 变体，避免内嵌普通表单的圆角框。增值税调整列通过通用 `formatEdit` 保留当前可见的 `0.00`，通过 `align/inputMode` 保持右对齐和小数键盘，整数分解析不变。未修改时离开不写回格式化值；修改后点击/聚焦外部会关闭编辑并校验提交，失败保留原值并用 Sonner 提示。Enter/Tab 校验失败时仍可继续修正，Esc 取消。通过实例级的编辑作用域区分下拉弹层、保存/取消和外部操作，防止取消时被提前保存、异步完成抢回焦点。

## 表头密度与列排序（2026-11-06）

分组行、列标题和数据行共同响应密度，并按原分组行规格保持等高：紧凑 1.75rem、标准 2rem、宽松 2.5rem。表头和分组令牌引用数据行令牌，控制器的无 DOM 回退同步为 28/32/40px；控制器直接按当前 density 读取共享 rem 令牌，避免 React 更新属性前读取旧高度造成虚拟行偏移。筛选行保留容纳共享输入框的最小高度。列标题使用透明文字操作，鼠标悬停不出现按钮底色或阴影，键盘聚焦仍有焦点标记。

列标题 hover 或键盘聚焦时显示 ReUI Sortable 手柄。按保存的 pinned 状态分成两个独立排序区域，鼠标、触摸与键盘沿用共享组件；只添加水平轴约束。窄窗临时解除视觉冻结不会改变排序区域。提交时 `reorderVisibleColumns(ids, pinned)` 验证完整可见列排列，只替换对应状态槽位，保留隐藏列及另一区域；菜单左右移动同样使用 `canMoveColumn` 限制。列顺序改变后正文、分组和汇总跟随相同布局，未增加业务数据写入或新的视图持久化。

## 快速滚动、右键插行与列落位（2026-11-06）

## 渲染与搜索性能（2026-11-07）

以 `999c21d` 为对照，将原正文行/格拆为浅比较的 `GridRow` 与 `GridCell`，DOM、共享控件、事件和稳定 key 不变。行只接收自己的选区、编辑与校验状态；草稿由当前 `CellEditor` 单独订阅，工具栏和其他单元格不随每次输入重绘。布局快照仍响应编辑生命周期及测量通知，即使虚拟范围数值相同也会更新 rem/密度几何。列布局按列定义、列状态、视口宽度和行号宽度缓存。
