# 源码注释规范

维护日期：2026-10-04。

手工维护的源码文件头说明职责、可核实的创建/修改时间、版本作用、主要调用关系、功能和预期结果。创建时间以 Git 首次收录或本次实际新建日期为据，不伪造历史；修改时间仅在实际修改文件时更新。

调用关系只列主要真实依赖和使用入口，不维护完整导入图，不把测试字符串中的模块名算作真实导入。版本作用解释本文件承担的边界，不重复口号。历史文件头中的已移除目录应在涉及该文件时校正。

公开工厂、API、资源生命周期、持久化和安全边界说明参数、结果、失败条件及资源所有者；简单展示组件与直观的局部函数无需逐行翻译。

JSON、锁文件、字体/图片、上游许可证和自动生成文件不强塞手工文件头。生成文件标注生成器和生成命令；源代码与生成器共同控制其内容，不手工修改生成结果。SQL 迁移保留生成工具的格式和历史，不为补注释改写已应用迁移。

代码注释解释当前行为；迁移来源、版本升级和长篇操作流程放在对应文档。不要把临时工具调用失败或对 AI 的指令写进源码。
